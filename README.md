## 🧠 Problem-Solving Approach

For every problem, I aim to follow this process:

1. **Understand the Problem** – Identify inputs, outputs, and constraints.
2. **Think Independently** – Develop a solution without immediately looking at the answer.
3. **Brute Force** – Start with a straightforward approach.
4. **Optimization** – Identify opportunities to improve the solution.
5. **Complexity Analysis** – Calculate time and space complexity.
6. **Implementation** – Write a clean Java solution.
7. **Review** – Understand mistakes and revisit difficult problems.
